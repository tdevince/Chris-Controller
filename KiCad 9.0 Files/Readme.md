This folder contains the KiCad files for the schematic and PCB layout
in the formate required by JLCPCB.com.  Also included is the BOM and
position file that JLCPCB requires for assembly.  The BOM and postion
file do not include information the push buttons, connectors or
ESP32-S2-Solo-2 module since these are manually soldered after
receipt of the manufactured PCB's.
